> **守职而不废，处义而不回，见嫌而不苟免，见利而不苟得，此人之杰也。**
> ——素书·正道章
**点破**：素书分人才三等——俊（德足怀远）、豪（行为表率）、杰（即本句：守职、守义、不苟免、不苟得）。判断托付对象，**最要紧是「见利而不苟得」**：钱面前不变形的人，才谈得上可靠。
**什么时候用**：判断合作者、下属值不值得托付大东西（钱、权、后背）。

## 素书 · 修身十八条

这一章全是"这么做，是为了解决那个问题"的句式，**可以直接当自查清单用**。

| 原文 | 为了什么 | 现在怎么用 |
|---|---|---|
| 绝嗜禁欲，所以除累 | 去掉负累 | 砍掉消耗你的嗜好和执念 |
| 抑非损恶，所以禳过 | 消除过错 | 压制邪念、减少恶行 |
| 贬酒阙色，所以无污 | 不受污染 | 节制饮酒女色，保持清醒 |
| 避嫌远疑，所以不误 | 不出差错 | 主动避嫌，别让自己说不清 |
| 博学切问，所以广知 | 增广见识 | 广泛学习 + 追着问 |
| 高行微言，所以修身 | 修养自身 | 做得多、说得少 |
| 恭俭谦约，所以自守 | 守住自己 | 低调收敛才能自保 |
| 深计远虑，所以不穷 | 不致困窘 | 想得深、看得远才不会走到绝路 |
| 亲仁友直，所以扶颠 | 危难有人扶 | 亲近仁者、结交直友 |
| 近恕笃行，所以接人 | 与人相处 | 宽恕 + 踏实做事 |
| 任材使能，所以济物 | 把事办成 | 用人所长，材与能分开用 |
| 殚恶斥谗，所以止乱 | 止住混乱 | 铲除恶人、斥退谗言 |
| 推古验今，所以不惑 | 不被迷惑 | 拿历史验证当下 |
| 先揆后度，所以应卒 | 应付突发 | 先估量再判断，遇事不慌 |
| 设变致权，所以解结 | 解开死结 | 变通 + 权衡，解不开的结用权变 |
| 括囊顺会，所以无咎 | 不出祸患 | 该闭嘴时闭嘴，顺应时势 |
| 橛橛梗梗，所以立功 | 建立功业 | 坚定不移、不可动摇 |
| 孜孜淑淑，所以保终 | 善始善终 | 勤勉不懈、始终向善 |

**最值得单独拎出来的三条**：

> **夫志心笃行之术：长莫长于博谋，安莫安于忍辱，先莫先于修德，乐莫乐于好善，神莫神于至诚，明莫明于体物，吉莫吉于知足，苦莫苦于多愿，悲莫悲于精散，病莫病于无常，短莫短于苟得，幽莫幽于贪鄙，孤莫孤于自恃，危莫危于任疑，败莫败于多私。**
> ——素书·本德宗道章
**点破**（挑最要命的六条）：

| 原文 | 白话 | 什么时候用 |
|---|---|---|
| **安莫安于忍辱** | 最稳妥的没有比忍辱更稳的 | 他在忍和翻脸之间摇摆 |
| **吉莫吉于知足** | 最吉利的没有比知足更吉的 | 该收手时舍不得 |
| **苦莫苦于多愿** | 最苦的没有比欲望太多更苦的 | 他什么都想要，摊子铺太大 |
| **孤莫孤于自恃** | 最孤独的没有比自以为是更孤的 | 他觉得自己什么都行、听不进去话 |
| **危莫危于任疑** | 最危险的没有比任用自己怀疑的人更险的 | 他一边怀疑一边用着某人 |
| **败莫败于多私** | 最败事的没有比私心太重更败的 | 分配不公、赏罚凭亲疏 |

**「危莫危于任疑」这一条特别狠**——你怀疑一个人还在用他，这是所有危险里最危险的一种。（张商英注：汉疑韩信而任之，而信几叛。）**这条几乎是写给所有合伙关系看的。**

## 素书 · 用人避祸

**这是全书最长、也最实用的一章**，几乎全是"你这么干，就会得到那个下场"。做管理、带团队、处关系，**优先来这一章找**。

### 关于自己

| 原文 | 会怎样 | 什么时候用 |
|---|---|---|
| 以明示下者暗 | 在下属面前显摆聪明，反而昏聩 | 他总想证明自己比人强 |
| 有过不知者蔽 | 有过错自己不知道，就会受蒙蔽 | 他从不复盘、听不进批评 |
| 迷而不返者惑 | 陷进去不回头，就是糊涂 | 他明知是坑还往里走 |
| 以言取怨者祸 | 说话招人怨恨，要惹祸 | 他嘴上不饶人 |
| 令与心乖者废 | 嘴上说的和心里想的不一致，政令就废了 | 他心口不一，团队不信他 |
| 后令缪前者毁 | 后面的命令和前面的矛盾，事业就毁了 | 他朝令夕改（团队迷茫的头号原因） |
| 怒而无威者犯 | 光发火却没有威信，下属就会冒犯 | 他靠吼管人 |
| 好众辱人者殃 | 当众羞辱别人，自己要遭殃 | 他在群里、会上批人 |
| 慢其所敬者凶 | 怠慢本该敬重的人，凶险 | 他冷落了关键的老关系 |
| 自厚而薄人者弃废 | 对自己宽厚、对别人刻薄，会被抛弃 | 他什么都给自己留、给别人少 |

### 关于识人

| 原文 | 会怎样 | 什么时候用 |
|---|---|---|
| 貌合心离者孤 | 表面和气内心背离的，最终孤立 | 判断合作关系真不真 |
| 亲谗远忠者亡 | 亲近谗佞、疏远忠直的，要败亡 | 他身边围着说好话的人 |
| 近色远贤者惛 | 亲近小人、远离贤人的，会昏聩 | 他用人的标准跑偏了 |
| 用人不得正者殆 | 用的人不正派，危险 | 他明知某人人品有问题还在用 |
| 强用人者不畜 | 硬留的人，留不住 | 他想强留要走的人 |
| 为人择官者乱 | 为了安排人而设岗位，会乱 | 他因人设岗、因人废事 |
| 所任不可信，所信不可任者浊 | 任用的人不可信、信任的人不能任用，局面就浑浊 | 整个组织人事错位的总诊断 |

### 关于带团队

| 原文 | 会怎样 | 什么时候用 |
|---|---|---|
| **小功不赏，则大功不立。小怨不赦，则大怨必生** | 小功劳不奖，大功劳就立不起来；小怨恨不化解，大怨恨必然产生 | 团队没动力、积怨已深 |
| 赏不服人，罚不甘心者叛 | 赏了人不服、罚了人不甘，就会背叛 | 分配方案要出台前 |
| 赏及无功，罚及无罪者酷 | 赏了没功劳的、罚了没罪过的，是暴虐 | 他凭亲疏赏罚 |
| 既用不任者疏 | 用了人又不给实权，人心就疏远 | 他授权不彻底（管理最常见的坑） |
| 行赏吝色者沮 | 行赏时面带吝惜，会让人灰心 | 给好处时姿态难看 |
| 多许少与者怨 | 承诺多兑现少，招人怨恨 | 他习惯性画饼 |
| 以过弃功者损 | 因为一次过错就抹掉全部功劳，会受损 | 他想开掉一个有过但有大功的人 |
| 戮辱所任者危 | 羞辱自己重用的人，危险 | 他当众贬低下属 |
| 牧人以德者集，绳人以刑者散 | 用德行凝聚人，人心聚；用刑法约束人，人心散 | 团队留不住人 |
| 闻善忽略，记过不忘者暴 | 听见好话不理、记住过错不放，是暴虐 | 他只看得见下属的错 |
| 听谗而美，闻谏而仇者亡 | 听谗言就高兴、听劝谏就仇视，要败亡 | 他身边没人敢说真话 |

### 关于决策

| 原文 | 会怎样 | 什么时候用 |
|---|---|---|
| **决策于不仁者险** | 跟不仁的人商量决策，危险 | 他找错人商量（这条最容易被忽略） |
| **阴计外泄者败** | 秘密计划泄露，必败 | 他还没干就到处说 |
| 厚敛薄施者凋 | 聚敛多、施予少，会衰败 | 分配严重向自己倾斜 |
| 战士贫，游士富者衰 | 干活的人穷、耍嘴的人富，就衰落 | 团队里干实事的吃亏、会说的得利 |
| 贵而忘贱者不久 | 富贵了就忘了穷贱时的交情，长不了 | 他起来之后疏远老关系 |
| 念旧而弃新功者凶 | 记着旧怨就抹杀新功劳，凶险 | 他翻旧账、不肯给机会 |
| **能有其有者安，贪人之有者残** | 安于自己该有的就安稳，贪图别人所有的就残败 | 眼红别人的、想抢 |

## 素书 · 安礼章

> **善为士者不武，善战者不怒，善胜敌者不与，善用人者为之下。**
> ——道德经·六十八章
**点破**：真正会做将领的不逞勇武，会打仗的不动怒，会胜敌的不硬拼，会用人的肯放低自己。
**什么时候用**：他被情绪推着要去"干一仗"。

## 道德经 · 强弱与柔弱

> **治大国若烹小鲜。**
> ——道德经·六十章
**点破**：治理大国像煎小鱼——不能老翻动，翻多了就碎了。毛亨注得最准：**烹鱼烦则碎，治民烦则乱**——朝令夕改，团队就被折腾散架了。
**什么时候用**：他频繁改方向、反复折腾团队或项目。

---

## 道德经 · 成大器

> **大方无隅，大器晚成，大音希声，大象无形。**
> ——道德经·四十一章
**点破**：最大的方正没有棱角，最大的器物最后完成，最大的声音听不见，最大的形象没有形状。
**什么时候用**：他着急、觉得同龄人都起来了自己还没有。

## 道德经 · 各有其根


> **今子有大树，患其无用，何不树之于无何有之乡，广莫之野，彷徨乎无为其侧，逍遥乎寝卧其下？**
> ——《庄子·逍遥游》
**点破**：惠子嫌樗树大而无用，木匠看都不看。庄子说：把它种到广阔的原野上，你在树旁躺卧，它自在生长。**不是树没用，是种错了地方。**
**什么时候用**：他给人下了"没用"的判词，或他自己被判定"没用"、自我怀疑。**换一片土，无用之用自己会长出来**——与「常善救人，故无弃人」配套：那句讲没有废人，这句讲换个地方活。

### 编外弹药（实战校准）

> **与人不求备，检身若不及。**
> ——尚书·伊训
**点破**：对人不必求全责备，检点自己却总怕做得不够。
**什么时候用**：他对伙伴苛刻、对自己宽容。一句话把秤摆正。

> **相益则亲，相损则疏。**
> ——鬼谷子·谋篇
**点破**：彼此受益就亲近，彼此受损就疏远——关系的本质是利益流向。
**什么时候用**：他在纠结一段合作/关系还要不要维持。别谈感情，先算利益流向：还在互相成全吗？

> **以其甚喜之时，往而极其欲也；以其甚惧之时，往而极其恶也。**
> ——鬼谷子·揣篇
**点破**：想看清一个人，挑他最高兴的时候去放大他的欲望，挑他最恐惧的时候去看他的厌恶——**情绪越极端，真心越藏不住**。
**什么时候用**：他看不清一个人的真面目、拿不准要不要深交/合作。别在饭桌上看人，**看他在得意时怎么待人、吃亏时怎么反应**——那才是真的他。

> **主孰有道？将孰有能？天地孰得？法令孰行？兵众孰强？士卒孰练？赏罚孰明？吾以此知胜负矣。**
> ——孙子·始计篇（七计）
**点破**：哪一方上下同心？哪一方将领有本事？哪一方占天时地利？哪一方令行禁止？哪一方实力强？哪一方训练有素？哪一方赏罚分明？靠这些我就知道胜负了。
**什么时候用**：**让他逐项给自己打分**。七计里输四项以上，这事就别干。

> **善战者，求之于势，不责于人，故能择人而任势。**
> ——孙子·兵势篇
**点破**：会打仗的人向"势"要结果，而不是苛责手下，所以他善于选人、善于借势。
**什么时候用**：他抱怨团队不行、下属不给力。**扎心的一句**——问题往往不在人，在你没造出势。

> **投之亡地然后存，陷之死地然后生。**
> ——孙子·九地篇
**点破**：把部队投到绝境才能存活，陷进死地才能求生。
**什么时候用**：**慎用**。这是绝境下的特殊手段，不是主动把团队逼上绝路。多数情况下，用它提醒"背水一战"需要极强的组织力做前提。

## 孙子 · 将的修养

> **不知三军之事，而同三军之政者，则军士惑矣。**
> ——孙子·谋攻篇
**点破**：外行硬插手打仗的事，带兵的人就糊涂了。
**什么时候用**：① 合伙人/股东不懂业务却要瞎指挥；② 反过来照他自己——**你是不是也在对自己不懂的那条线指手画脚**？

## 使用提醒

- 孙子是**利益导向**的，不含道德劝诫。用它时要提醒用户：合规、信誉、关系这些"非战场变量"不在孙子的计算里，得自己补上。
- 最常用、最不容易出错的三条：
  - 该不该动 → **合于利而动，不合于利而止**
  - 能不能赢 → **胜兵先胜而后求战**
  - 老是被动态 → **善战者，致人而不致于人**
- **别把兵法语汇直接搬进现代场景**——"攻城""伐兵"只是比喻，要说人话。

## 计篇 · 价值观与五事七计

> **上下同欲者胜。**
> ——孙子·谋攻
**点破**：孙子的"道"不是正义性，是「大家支不支持」。团队不齐，什么战略都白搭。
**什么时候用**：团队人心不齐 / 合伙人各怀心思 / 推不动事。

> **心里装着对方的利益，并有能力让对方清楚这一点。**
> ——西点军校领导力准则
**点破**：信的核心——首先你心里真装着对方，其次你得让对方知道。装着他却让他不知道，人就跑了。
**什么时候用**：带团队 / 合伙人之间信任出了问题 / 想让人跟你干。

> **大抵失败而归咎于谋主者，庸人之恒情也。**
> ——曾国藩
**点破**：成败无定，领导者要自己负决策责任。搞糟了怪出主意的人，是庸人常态。
**什么时候用**：决策失败怪军师 / 怪下属 / 不认自己那一锤。

> **动手前先算五样：人心、天时、地利、将才、规矩——算清楚了再动。**
> ——孙子·义理引申
**点破**：比较道（人心向背）、天（天时）、地（地利）、将（人才）、法（管理）——算清楚再动手。
**什么时候用**：要不要打这一仗 / 决策前做优劣势分析。

> **外面的墙难攻，里面的缝要命。有恩才有怨，恩有多大，怨就有多大。**
> ——孙子·义理引申
**点破**：和敌人是利益之争，简单；内部是爱恨情仇，复杂。外部竞争者最省力的打法，是参与你的内部竞争。
**什么时候用**：团队被离间 / 合伙反目 / 亲人反目。

> **军无财，士不来；军无赏，士不往。**
> ——曹操注《孙子》
**点破**：古今名将都有一个共同点——舍得给大家分钱，自己分文不取。自己不参与分，觉得不公平的人也没话说。
**什么时候用**：合伙分钱 / 团队激励 / 舍不得给。

> **队友犯了糊涂，你不必跟着糊涂——跟着错一次，是错两次。**
> ——孙子·义理引申
**点破**：队友犯了错，你跟着犯是二次错误。他真需要你的时候拉他一把，联盟反而更稳。
**什么时候用**：合伙/团队被带偏 / 队友决策愚蠢。

> **上头可以不懂你的专业，你不能不懂上头的顾虑。**
> ——孙子·义理引申
**点破**："将在外君命有所不受"是给老板立的规矩，但只能启发他自觉守规矩，不能假设他一定守。
**什么时候用**：跟老板/甲方意见相左 / 专业坚持还是服从。

> **你能带多少人，就是你有多大本事——不是计谋，是组织。**
> ——孙子·义理引申
**点破**：人们看到的是谋略勇敢（有故事、爱听），不被挂在嘴边的是组织、动员、管理（枯燥，但是真本事）。
**什么时候用**：团队扩张 / 管理能力跟不上。

## 后记 · 九条思想精要（去重后保留 4 条）

> 原书后记总结九条思想精要，其中 5 条与库内已有金句语义重复（先胜后战/以正合以奇胜/一战而定/诡道/数胜必亡），此处只收不重复的 4 条。

> **人情似纸张张薄，世事如棋局局新。**
> ——增广贤文
**点破**：人情薄如纸，世事每局都是新的。
**什么时候用**：他指望"老交情"扛住利益冲突，或者对过去的关系、过去的成功抱着不放。形势变了，牌就要重新算。

> **人亲财不亲，财利要分清。**
> ——增广贤文
**点破**：人是亲的，钱是冷的——关系再亲，利益也要算清楚。
**什么时候用**：亲人/好友合伙，他觉得谈钱伤感情、不好意思把账定死。**反过来才是真的：账不清，人最后才不亲**——跟"义者让之本，利者争之端"配套用。

> **夫义者，让之本也；利者，争之端也。**
> ——渔樵问对
**点破**：义是谦让的根本，利是争夺的开端。利益一旦摆上桌，争端就跟着来。
**什么时候用**：合作还没把利益规则说清楚就要开始干。丑话在先，是护住关系。

### 道德经 · 贵言与不居功

> **悠兮其贵言。功成事遂，百姓皆谓我自然。**
> ——道德经·十七章
**点破**：领导话太多就没分量、没意义。事情做成了，让团队觉得"是我们自己做成的"——你越指导他，他越没自信。
**什么时候用**：唠叨式管理 / 事事指导 / 抢功劳。
> **生而不有，为而不恃，长而不宰。**
> ——道德经·五十一章【全书最精彩的十二个字】
**点破**：创造了不占有；对人有恩不倚仗、不拿恩德当勒索的手段；做家长、做官长，不主宰儿女和属下的命运——一旦想主宰，就要反目成仇。
**什么时候用**：居功自傲 / 恩情绑架 / 控制欲强 / 对孩子"没有我你能成吗"。
> **后其身而身先，外其身而身存。非以其无私邪？故能成其私。**
> ——道德经·七章
**点破**：把自己的利益放到后边，反而被大家推到前边；凡事私字当头拼命抢，失去的更多。
**什么时候用**：抢好处 / 争利益 / 团队离心。
> **我有三宝，持而保之：一曰慈，二曰俭，三曰不敢为天下先。**
> ——道德经·六十七章
**点破**：慈故能勇（有担当才有真勇敢）；俭故能广（节俭之风才能长久持续）；不敢为天下先（先人后己，才能帮底下的人成器成长）。
**什么时候用**：领导三样宝贝丢了一样 / 团队没有节俭之风 / 好大喜功。
> **音声相和——不允许人有不同意见，就永远只有一种声音。**
> ——道德经·义理引申（二章）
**点破**：这一辈子进步，从对手那里得到的，比从朋友那里得到的多。朋友天天说"别干了，我罩着你"，那是把你坑了。
**什么时候用**：听不进不同意见 / 身边全是捧场的 / 把提意见的当敌人。

### 道德经 · 不尚贤与无私

> **不尚贤，使民不争。**
> ——道德经·三章
**点破**：一给"贤"定标准，人就按标准剪裁自己、投机取巧——真正有才能的人不屑于按你的标准打扮自己，反而被漏掉。
**什么时候用**：考核标准僵化 / 人才选拔一刀切 / 按指标凑人才。
> **天地不仁，以万物为刍狗；圣人不仁，以百姓为刍狗。**
> ——道德经·五章
**点破**："不仁"不是残忍，是无偏私——好的领导对众人公平，不私自照顾哪一方。越扶越扶不起来，他觉得该的。
**什么时候用**：偏心偏爱 / 对弱者过度照顾 / 规则因人而异。
> **民之难治，以其上之有为。**
> ——道德经·七十五章
**点破**：下面难管，是上面瞎折腾把人心搞乱了——别老怨他们。
**什么时候用**：团队难带 / 天天变章法 / 折腾式管理。

### 道德经 · 上善若水
> **处众人之所恶，故几于道。**
> ——道德经·八章
**点破**：水去的是大家都不愿去的又低又脏的地方——受国之垢、处众人之所恶，把脏活累活揽下来，两千年是一个道理。
**什么时候用**：挑肥拣瘦 / 脏活累活没人干 / 领导不肯下场。
> **政善治——政清如水。**
> ——道德经·八章
**点破**：水的品德是公平公正（一碗水端平）+ 激浊扬清（清廉）。治理的"治"只能用三点水的"治"，不能用刀制。
**什么时候用**：分配不公 / 规则双标 / 团队风气坏。

### 道德经 · 虚静与有无
> **我无为而民自化，我无事而民自富。**
> ——道德经·五十七章
**点破**：规则定清楚了，放给团队自己干——别认为什么事都得你来弄，别老干扰干涉捆绑束缚。
**什么时候用**：管得太细 / 不放权 / 团队没有自主性。
> **常善救人，故无弃人；常善救物，故无弃物。**
> ——道德经·二十七章
**点破**：智慧高的人眼里没有无用之人——他只是没按你期待的方式有用而已。别老说自己儿女无用、说成员不行。
**什么时候用**：给人贴"没用"标签 / 放弃团队成员 / 只看见别人的短处。

### 道德经 · 规律与领导层次
> **太上，下知有之。其次，亲而誉之。其次，畏之。其次，侮之。**
> ——道德经·十七章
**点破**：领导四层次——最好的领导，在不在都一样（制度顺理成章）；次一等大家亲近赞誉（但自己累死）；再次大家畏惧（严刑重罚）；最差被推翻羞辱。**"这个单位没我不行"——你把自己看得太重要了。**
**什么时候用**：领导层次自检 / 事事插手 / 离了我就转不动。
> **为之于未有，治之于未乱。**
> ——道德经·六十四章
**点破**：扁鹊三兄弟——大哥治病于未发没人感谢，二哥治小病，扁鹊治大病成名医。**堵蚂蚁窝的人没人感谢，但那才是真智慧**。
**什么时候用**：救火式管理 / 没有预见性 / 事后诸葛。

### 道德经 · 德经开篇·上德不德
> **大道氾兮，其可左右。衣养万物而不为主。**
> ——道德经·三十四章
**点破**：道对万事万物有恩德，却不以主宰者身份出现——不说"你们都靠我，该感恩我"。有恩不图报，才是真的有德。
**什么时候用**：恩人自居 / 控制欲 / "没有我你们能怎样"。

### 道德经 · 大成若缺与为道日损
> **清静为天下正。**
> ——道德经·四十五章
**点破**：内心清静才能引导天下走正道——躁胜寒（运动克寒），静胜热（冷静克躁）。领导者自己先静下来。
**什么时候用**：团队浮躁 / 自己先乱了 / 静不下心做决策。

### 道德经 · 圣人无常心·成功四要素
> **圣人无常心，以百姓心为心。**
> ——道德经·四十九章
**点破**：不固执己见，换位思考将心比心。善者吾善之，不善者吾亦善之（德善）；信者吾信之，不信者吾亦信之（德信）——让天下人向善、向诚信。
**什么时候用**：固执己见 / 不懂换位思考 / 以自我为中心。

### 道德经 · 全书收尾·五十三章至八十一章
> **其政闷闷，其民淳淳；其政察察，其民缺缺。**
> ——道德经·五十八章
**点破**：管得宽厚，下属就淳朴实诚；管得苛刻、什么都盯，下属反而心眼越来越多——你出一条规矩，他就想一条应对，全是逼出来的。
**什么时候用**：他想加流程、加审批、加监控来堵漏。提醒他：防住了小鬼，磨掉了人心。
> **以正治国，以奇用兵，以无事取天下。**
> ——道德经·五十七章
**点破**：治国靠堂堂正道，打仗才可以用奇巧——两套打法不能混。把兵法那套诡道、套路搬到日常带团队上，赢一次小仗，输掉整个人心。
**什么时候用**：他琢磨着用"手段"管人、设局整人。带团队走正道才是长久打法。
> **以智治国，国之贼。**
> ——道德经·六十五章
**点破**：靠心眼和套路治理组织，是组织的祸根。底下人为什么难管？心眼多——而下面的心眼，多半是上面的套路教出来的。
**什么时候用**：他抱怨团队心眼多、互相防——先带他照镜子：上面怎么对下面，下面就怎么对上面。
> **代大匠斫者，希有不伤其手。**
> ——道德经·七十四章
**点破**：替木匠抡斧子的人，很少有伤不到手的。越俎代庖、抢着替下属干活——活干砸了算谁的？自己累垮、人也废了，两手都伤。
**什么时候用**：他嫌下属做得慢做得差，忍不住亲自下场——提醒他：不让下属在事上练，团队永远练不出来。
> **圣人执左契，而不责于人。**
> ——道德经·七十九章
**点破**：手里攥着别人欠的借据，却不追着讨——帮过人的恩，别天天挂在嘴上。一旦开口讨还，恩就变成了债，人情反而没了。
**什么时候用**：他老觉得"我帮了他这么多，他怎么不感恩"、逢人就翻旧账——恩一旦被讨要，就一文不值。

### 论语 · 事业合伙金钱执行
> **先有司，赦小过，举贤才。**
> ——论语·子路
**点破**：带团队九个字：事有专责（别啥都自己抓，抓着抓着组织就废了）、小错要赦（别因为一件小事就把人否了——你假设人人都是坏人，就总能发现好人）、人才要举。
**什么时候用**：他事必躬亲、容不得下属一点小错、还说招不到人——九个字甩给他。
> **举尔所知。尔所不知，人其舍诸？**
> ——论语·子路
**点破**：人才要向内找：把你手下调教好、用到位，全天下的人才自然来；向内的功夫没做好，在身边的人也会走。十年老员工里，往往埋着一个全明星队。
**什么时候用**：他总说"招不到人"、猎头花了几十万——先问：手上的这几个，用尽了吗？
> **近者悦，远者来。**
> ——论语·子路
**点破**：让身边人高兴，外面的人才自然想加入——一家公司好不好，员工和前员工最知道。想吸引人才，别出去抢，先把手底下的人伺候明白。
**什么时候用**：他想扩张招人、到处挖角——先看离职员工说他什么。
> **能行五者于天下为仁矣：恭、宽、信、敏、惠。**
> ——论语·阳货
**点破**：带人五字诀：恭敬（对谁都客气，包括对下级）、宽厚（允许人犯错——惩罚错误，人人就都藏错误）、守信（说到做到）、勤快、给钱。最后一条最实在：什么都肯给就是不肯给钱的，成不了事——这世界大多数事，就是钱的事。
**什么时候用**：他抱怨下属没忠诚度——对照五字，多半缺的是最后那个"惠"字。
> **犹之与人也，出纳之吝，谓之有司。**
> ——论语·尧曰
**点破**：该给的赏赐攥在手里磨磨叽叽，印的角都磨圆了还舍不得发——项羽就输在这。能付出感情，付不出钱，做不成大事。分钱手紧的领导，兵都跑光。
**什么时候用**：他承诺的奖金分红一拖再拖、扣扣索索——提醒他：钱关比美人关难过，但必须过。
> **虽有周亲，不如仁人。**
> ——论语·尧曰
**点破**：靠"自己人"本身就是私心：豪门多恩怨，有多大的恩就有多大的怨；你最信的心腹，捅你捅得最准——因为他知道你不会把他怎么样。仁德的领导者没有心腹——你对所有人讲信用，天下人都是你的心腹。
**什么时候用**：他把团队分成"自己人"和"外人"、重要的事只放心腹——萧墙之祸就是这么埋的。
> **君子信而后劳其民；未信，则以为厉己也。信而后谏；未信，则以为谤己也。**
> ——论语·子张
**点破**：信任是前提：没取得信任就去使唤人，人觉得你在折腾他；没取得信任就去进谏，人觉得你在诽谤他。想推任何改革、说任何重话，先攒够信任。
**什么时候用**：他抱怨"好心当驴肝肺"、推行新制度全员抵制——不是方案错了，是信任余额不足。
> **臧文仲其窃位者与？知柳下惠之贤，而不与立也。**
> ——论语·卫灵公
**点破**：明知有贤才却不举荐、不培养——就是占着位子偷东西。管理者的头号罪过不是业绩差，是任职多年一个新人没带出来。能举荐一个和自己一样强的人，贡献翻倍。
**什么时候用**：他培养人敷衍、怕徒弟抢位子——用"窃位"两个字点醒他。
> **其身正，不令而行；其身不正，虽令不从。**
> ——论语·子路
**点破**：你自己行得正，不用下命令，大家跟着干；你行不正，说破嘴也没人听。要求别人做到的，自己先做到——自己没做到的，就别要求别人。
**什么时候用**：他抱怨团队执行力差——先查自己：你要求的那些，你自己做到了几条？
> **浸润之谮，肤受之愬，不行焉，可谓明也已矣。**
> ——论语·颜渊
**点破**："明"的考验不是不被明着骗，而是不被日复一日的谗言、哭得撕心裂肺的诉冤带偏。方法：掌握一手信息（比说的人知道得多）、对人先有自己的判断（不因一句传话翻烙饼）、允许自己偶尔被骗（被骗预算）。
**什么时候用**：他偏听偏信、今天信这个明天信那个、被人当刀使——送他这三个防挑拨的动作。
> **百姓足，君孰与不足？百姓不足，君孰与足？**
> ——论语·颜渊
**点破**：分钱的天使循环：员工富了，公司才富。老板问"给员工加钱，我不拿得更少了吗"——这问题问出来，公司就到头了。越舍不得分，越没人跟你把事做大；舍出去的钱，长回来的更多。
**什么时候用**：他抠分红、压工资、算计员工——用这句反问问醒他。
> **居敬而行简。**
> ——论语·雍也
**点破**：自己要恭敬严谨，对下面要宽简——可以放松别人，不能放松自己。反过来的领导（对自己松、对下面苛）团队必散。
**什么时候用**：他对下属抠规矩、自己却带头破例——把顺序倒过来。
